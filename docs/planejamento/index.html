Para gestores de marketing, empresários e equipes comerciais de indústrias e empresas B2B que querem organizar suas prioridades para 2027.

Preciso ter todos os números em mãos?

Não. Você pode usar estimativas para suas metas e selecionar “Ainda não definido” nos campos de orçamento. As respostas podem ser revisadas depois.

Onde minhas respostas ficam salvas?

Somente no localStorage deste navegador, neste dispositivo. Não enviamos suas respostas para um servidor. Limpar os dados do site ou usar uma janela anônima pode apagar seu progresso.
